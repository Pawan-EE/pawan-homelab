# Roadmap

These are proposed improvements, not completed features.

## Establish a verified baseline

- [ ] Confirm exact CPU, memory, Ubuntu release, and disk inventory.
- [ ] Record sanitized logical-volume sizes and filesystem roles.
- [ ] Record running container versions and persistent-data locations privately.
- [ ] Verify protected routes with allowed, denied, and signed-out users.
- [ ] Verify reboot persistence and a local recovery path.

## Improve resilience

- [ ] Define backup retention and an independent backup destination.
- [ ] Perform and document a restore test with non-sensitive evidence.
- [ ] Add capacity, temperature, and service-failure monitoring.
- [ ] Document update and rollback procedures per application.

## Reduce routine terminal work

- [ ] Refine Homepage links and graphical management workflows.
- [ ] Evaluate narrowly scoped action buttons for routine maintenance.
- [ ] Prototype a NAS assistant with read-only diagnostics first.
- [ ] Evaluate a chat interface such as Open WebUI and an appropriate model backend.
- [ ] Require explicit approval for changes and keep an audit trail.
- [ ] Avoid unrestricted sudo or Docker socket access for an AI assistant.

## Extend the lab

- [ ] Evaluate additional website hosting.
- [ ] Explore Navidrome as a separate future service.
- [ ] Explore ESP32/IoT experiments with deliberate network isolation.
- [ ] Add sanitized diagrams or screenshots after privacy review.
